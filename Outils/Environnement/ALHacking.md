# ALHacking

Script **tout-en-un** (bash) qui installe/lance une collection d'outils, sous
**Termux (Android)** et Linux Debian/Unix.

> 🚩 **Avertissement — outil à faible valeur pédagogique et partiellement
> problématique.** Le menu inclut des modules sans usage légitime autorisé
> (**« DDOS attack tool »**, « Gmail attack », « phone number attack »,
> « Webcam Hack »). Ce type de script « tout-en-un » est surtout du niveau
> *script-kiddie* et certains modules sont **illégaux à utiliser contre autrui**.
> Je le référence pour **connaître son existence**, pas pour l'employer tel quel.
> Aucune de ces fonctions ne doit viser une cible sans autorisation. Cf. `README`.

## Contenu annoncé
Ethical hacking, hack de réseaux sociaux, infos téléphone, « Gmail attack »,
« phone number attack », découverte d'utilisateur, « Webcam Hack », outil de DDoS.

## Installation (pour référence)
```bash
pkg install git                # (Termux)
git clone https://github.com/4lbH4cker/ALHacking
cd ALHacking
bash alhack.sh
```

## Position
Pour un travail sérieux, préférer des outils ciblés et maintenus (ceux des autres
catégories `Outils/`) plutôt qu'un agrégateur opaque. À garder à l'esprit surtout
pour **reconnaître** ce genre de toolkit quand on le croise.
